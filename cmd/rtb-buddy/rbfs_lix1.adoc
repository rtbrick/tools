==== rbfs lix1

Generates RBFS LI X1 mTLS CLI `set` commands from certificates and sends PingRequest.

===== rbfs lix1 server certificate

Generates server certificate and key configuration commands.

* `--cert` — Server certificate PEM file (required)
* `--cert-key` — Server private key PEM file (required)

[source,sh]
----
rtb-buddy rbfs lix1 server certificate --cert server.crt --cert-key server.key
----

Outputs:
```
set lawful-intercept protocol x1 mutual-tls server certificate <base64>
set lawful-intercept protocol x1 mutual-tls server key-plain-text <base64>
```

===== rbfs lix1 ping

Send X1 PingRequest to RBFS router (LI X1 over mTLS).

* `--cert` — Client certificate PEM file (required)
* `--cert-key` — Client private key PEM file (required)
* `<path>` — Router hostname or address (required)

[source,sh]
----
rtb-buddy rbfs lix1 ping <path> --cert client1.crt --cert-key client1.key
----

Output:
```
Status: 200
Content-Type: application/xml
Response:
<?xml version="1.0" encoding="UTF-8"?>
<X1Request xmlns="http://uri.etsi.org/03221/X1/2017/10">
  <x1RequestMessage xsi:type="PingRequest">
    <admfIdentifier>ADMF-ID-01</admfIdentifier>
    <neIdentifier>NE-ID-102</neIdentifier>
    <messageTimestamp>2026-01-15T12:00:00Z</messageTimestamp>
    <version>v1.12.1</version>
    <x1TransactionId>f81d4fae-7dec-11d0-a765-00a0c91e6bf6</x1TransactionId>
    <pingType>basic</pingType>
    <requestedNumberOfRepetitions>1</requestedNumberOfRepetitions>
  </x1RequestMessage>
</X1Request>
```
